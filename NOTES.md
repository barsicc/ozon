# Карта дарксторов Ozon fresh — записка о проекте

Цель: сайт (GitHub Pages, https://barsicc.github.io/ozon/) с картой всех дарксторов Ozon fresh,
геопозицией, списком ближайших, поиском и кнопкой «Скопировать адрес». Сотрудник копирует адрес
склада и вставляет его там, где выбирает склад для заказа со скидкой.

## Данные — `data/darkstores.json`
445 записей, на карту (`show: true`) — 439. Поля:

| поле | что это |
|---|---|
| `id` | транслит названия в системе, например `fresh_grc_msk_litovskiy` |
| `region` | раздел страницы Ozon: «Москва и МО», «Санкт-Петербург», … |
| `name` | короткое название, как на странице («Лобачевского») |
| `system` | название в системе Ozon (`FRESH_MAX_МСК_ЛОБАЧЕВСКОГО`) |
| `address` | фактический адрес (как в источнике, ещё не нормализован) |
| `status` | `ok` — страница Ozon / 2ГИС / документ Ozon; `app` — подтверждено в Ozon Job; `dup` — дубль другой точки; `gone` — нет в Ozon Job, вероятно закрыт |
| `source` | откуда адрес |
| `how` | «как добраться» (пока только у 4 складов, из Ozon Job) |
| `schemes` | схемы проезда: `images/schemes/*.jpg` (389 шт., карта со стрелками к входу и условия разгрузки) |

Реквизиты (ИНН/КПП, счета, GLN, GUID) сознательно не храним.

## Источники и доверие
1. **Страница Ozon «Адреса и реквизиты складов Ozon Fresh»** (seller-edu, сохранена 16.11.2026, 470 МБ,
   SingleFile) — главный источник, ему доверяем. 452 записи по РФ; 57 без фактического адреса
   (старый формат `FRESH_MAX_…` и РЦ). Разбор: `tools/strip_images.py` → `tools/parse_stores.py` → `tools/build_dataset.py`.
2. Для 57 без адреса — `data/bez_adresa.txt`: 2ГИС, документ Ozon «Баллы на Дарксторах Фреш» (п. 1.6),
   проверка пользователем в приложении Ozon Job. РЦ (Рябиновая, Бугры — Шоссейная, ДС Лиговский, Шапсугское) исключены.
3. Ozon Job (приложение) — самый свежий источник: у каждого склада адрес и «Как добраться». Веб-версии нет.

## Решения
- Карта и поиск — Яндекс (JavaScript API + HTTP Геокодер). Ключ — секрет репозитория `YANDEX_MAPS_API_KEY`;
  в чат не передаётся. После публикации пользователь ограничивает ключ по HTTP Referer `barsicc.github.io`.
- Публикация — GitHub Pages, источник «GitHub Actions» (уже включён).
- Сайт без бренда Ozon, с пометкой «неофициальная карта»; в поисковики не попадает (noindex).
- Склады со статусом `gone` и `dup` на карту не ставим.
